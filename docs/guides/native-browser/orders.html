What this example does—and what remains

BroadcastChannel carries messages; Web Locks selects one coordinator. The coordinator renders its own changes and sends snapshots to peers. A joining tab requests a snapshot because broadcasts have no replay history.

State lives in memory in open tabs. Closing all tabs or reloading the last tab loses the order. There is no backend persistence, authentication, multi-device synchronization, reliable suspended-tab detection or transaction recovery. The note field stays in this tab only. Do not enter real orders or credentials.

Only the order-board behavior is exercised here. The textarea's sizing and popover are progressive enhancements: manual resizing and visible checks remain usable without them. This does not implement the talk's camera, screen share, Bluetooth or AI examples.
