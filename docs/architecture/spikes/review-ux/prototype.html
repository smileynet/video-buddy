Study scope and evidence limits
Two structural variants, the same content: A is a linear linked-document baseline; B puts instructions beside evidence. A is a Markdown-style linked document rendered as HTML, without requiring a particular editor/chat client. This is a layout comparison, not a benchmark of all Markdown tools. No backend, extraction request or file operation is connected. “Inspect” only opens existing evidence. Both offer identical note/pause controls.
Tasks address exact commands, a missing prerequisite, correction, provenance and resumption. One familiar participant doing both views cannot establish a causal usability advantage. Record order and request help honestly. Counterbalance the next fresh participant B→A, and use matched unseen tasks before quantitative claims. Ticket 21 owns fresh task performance.
