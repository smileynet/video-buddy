# S1 walkthrough protocol

No participant session has occurred. This is a prepared instrument, not a result.

Give a fresh task performer exactly one variant, `evidence.json` and the task brief. A first session can expose usability failures but cannot establish a format effect. Use counterbalanced variants on equivalent tasks or more independent readers before choosing a format winner.

Task 1: in an empty disposable directory, implement the circular motion task and produce a 360-row CSV. Do not provide the numeric probe implementation to the performer. Check constant radius, first point, row count and the performer's understanding of which parameters were adapted.

Task 2: explain whether the exact source square-wave recipe can be implemented from this packet. Success is identifying the missing coefficients and requesting evidence; writing a plausible unsourced recipe is a failure.

Record variant, source familiarity, environment, duration, checkpoints passed, interventions, source lookups, unsupported instructions and whether the performer can distinguish supported, adapted and executed status. Store consented results without personal data. Do not invent reader timing from an automated run.

Comparison limit: both variants intentionally contain the same substantive information, including the diagnostic consequence of zero phase. An automated structural observation is not a controlled usability result. Both variants came from one agent without a fixed generation-token budget, so the prepared artifacts do not establish a generation efficiency advantage.
